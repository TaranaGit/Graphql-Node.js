# 🎮 GraphQL Game Reviews API

Welcome to the **GraphQL Game Reviews API**!  
This is a lightweight GraphQL server built with Apollo Server, showcasing how to serve and query data for games, authors, and reviews using GraphQL.

## 🚀 Features

- Query game data by `ID` or `title`
- Fetch all reviews and authors
- Support for nested GraphQL queries (e.g., reviews within a game)
- In-memory data simulating a mini database

## 🛠 Setup Instructions

### Prerequisites
- Node.js
- Apollo Server
- GraphQL
### Running Locally
```bash

# Clone the repository
git clone git@github.com:TaranaGit/Graphql-Node.js.git
cd Graphql-Node.js

# Install Dependencise
npm install

# Run the Server
node server.js
 Server will start at 
 🔗 http://localhost:4000
```
